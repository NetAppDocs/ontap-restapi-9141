= Delete an FPolicy persistent store configuration for an SVM
:imagesdir: ./media/

[.lead]
Deletes a specific FPolicy persistent store configuration for an SVM, removing the associated data store settings.

== HTTP method and endpoint

[.api-doc-operation .api-doc-operation-delete]#DELETE# [.api-doc-code-block]#`/protocols/fpolicy/{svm.uuid}/persistent-stores/{name}`#

== Introduced in

ONTAP 9.14

== Related ONTAP commands

* `fpolicy persistent-store delete`

== Learn more

* link:manage_fpolicy_persistent_store_configuration.html[DOC /protocols/fpolicy/{svm.uuid}/persistent-stores]
