= Delete suspect files
:imagesdir: ./media/

[.lead]
Delete suspect files from the list of potential suspects for a volume using the suspects DELETE API. Use these endpoints when you need to ensure that suspect files are no longer flagged for review.

The suspects DELETE API clears all the suspect files for a volume from the list of potential suspects.
