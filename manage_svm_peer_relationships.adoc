= Manage SVM peer relationships
:imagesdir: ./media/

[.lead]
Utilize SVM peer relationship endpoints to create and manage peering connections between SVMs. These endpoints support the establishment and maintenance of communication and data exchange across storage virtual machines.

== Managing SVM peers

The SVM peer commands allow you to create and manage SVM peering relationships.

=== SVM peer APIs

The following APIs are used to manage SVM peers:

* GET /api/svm/peers
* POST /api/svm/peers
* GET /api/svm/peers/\{uuid}
* PATCH /api/svm/peers/\{uuid}
* DELETE /api/svm/peers/\{uuid}
