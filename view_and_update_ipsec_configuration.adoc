= View and update IPsec configuration
:imagesdir: ./media/

[.lead]
Access and modify IPsec configuration settings to secure data transmitted across your network. Use these endpoints to retrieve the current IPsec status or update it as necessary.

== Overview

The following operations are supported:

* GET to retrieve the IPsec status: GET security/ipsec
* Patch to update IPsec status: PATCH security/ipsec
